# AI Financial Crime Investigator

AI-powered financial crime investigator that detects suspicious transaction patterns, maps hidden transaction networks, traces money flows, and uses an NVIDIA-powered investigation agent to investigate cases and generate evidence-based reports.

## Project Status

🚧 Currently under development.

## Overview

Financial crime investigations require analysts to examine large volumes of transactions and complex networks of accounts to identify suspicious activity.

This project combines machine learning, transaction-network analysis, and an NVIDIA-powered AI investigation agent to support the investigation process.

## Core Capabilities

- Detect suspicious transaction behavior using machine learning
- Identify suspicious account networks
- Trace transaction flows across accounts
- Analyze behavioral and network risk indicators
- Investigate suspicious cases using an NVIDIA-powered AI agent
- Generate evidence-based investigation reports
- Provide human-reviewable recommended actions

## Data

The project uses synthetically generated financial transaction data created specifically for this project.

The dataset is generated programmatically and is not based on real individuals or real financial accounts.
